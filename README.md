# Agente Conecta Notifica

Serviço Windows que lê as marcações da catraca no SQL Server da escola e envia para o painel Conecta Notifica.

O código, a instalação e o build estão em [apps/agent](apps/agent).

O painel e a API ficam em outro repositório. Os contratos que o painel precisa implementar estão em [apps/agent/docs](apps/agent/docs).
