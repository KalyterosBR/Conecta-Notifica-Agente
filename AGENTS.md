## Escopo e segurança

- Projeto independente do Conecta Acesso. Não apontar este agente ao backend do Conecta Acesso sem um adaptador específico.
- O endereço documentado é `https://painel.conectapontoeacesso.com.br`, com API em `https://painel.conectapontoeacesso.com.br/api`.
- Nunca versionar binários, `config.yaml`, chaves `cn_*`, senhas SQL ou logs. A cópia importada pode conter arquivos `:Zone.Identifier` do Windows.
- O agente é exclusivamente leitor do TopPortaria: jamais criar, alterar ou excluir dados no SQL Server.

## Delegação de subagentes

- Delegar somente tarefas independentes e bem delimitadas quando isso reduzir tempo ou melhorar a revisão; mudanças pequenas devem ser feitas diretamente.
- Para criação, refatoração, correção e testes de código, usar `gpt-6-sol` com esforço `low`.
- Para leitura, levantamento de arquivos, verificações mecânicas e operações simples de Git (inclusive preparar commit ou push quando explicitamente solicitado), usar `gpt-6-luna` com esforço `low`.
- A pessoa que coordena a tarefa mantém a integração final, a revisão de segurança e a decisão de executar operações externas, como `git commit` e `git push`.
- Como todos os subagentes compartilham o diretório de trabalho, cada delegação deve informar os arquivos sob sua responsabilidade e preservar alterações paralelas.
